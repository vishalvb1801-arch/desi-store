What actually changed

Old behaviour on the left of each row, staged on the right.

Motionfade swap → marquee
JavaScriptsetInterval → none
Width480px box → full bleed
Wrapping2 cramped lines → 1 line
Height~34px → ~43px
Separatornone → gold ✦
Iconsnone → inline SVG
Messages2 → 3
Spacingfixed 18px → adjustable gap

Why wrapping and scrolling can't coexist. Scrolling text has to sit on one unbroken line, so the marquee sets white-space: nowrap. What was making the old bar wrap badly wasn't the text — it was the 480px box squeezing it. Full-bleed removes the squeeze entirely. Visitors who've switched on "reduce motion" get a centred, properly wrapped block with no animation instead.

Mirrors sections/eis-announcement-bar.liquid as staged on EIS PDP — Fv3 of Horizon. One difference worth knowing: the mobile rule here keys off the frame width, while the real theme keys off the browser viewport at 749px. Everything else — the min-width: 200% track, the -50% slide, the edge mask — is identical.
