Desktop Design Brief

Everything needed to design the desktop PDP in Claude Design without disturbing the finished mobile build. Generated from the live draft theme.

Short answer: yes. Design desktop freely and hand it back. Mobile can be locked completely — not by convention, but structurally. Desktop rules live inside a @media (min-width: 750px) block, and a phone browser never reads a single line inside that block.

Why desktop looks broken today

It isn't a styling problem. Every one of the 15 sections caps its content at 480px, and only 5 of them define any desktop behaviour at all. So on a 1440px monitor the whole page is a phone-width column stranded in the middle with ~480px of empty space either side.

Now — 1440px viewport
What desktop wants

Nothing is misaligned — there is simply no desktop layout yet. That is the thing to design.

How mobile stays locked

The theme's breakpoint is 750px. Below it, the current mobile CSS runs untouched. At and above it, your desktop rules apply. The rule for anything you hand back:

/* Mobile — already signed off. Do not touch. */
.eis-hero__title { font-size: 31px; }

/* Desktop — everything new goes in here */
@media (min-width: 750px) {
  .eis-hero__title { font-size: 44px; }
}

The one thing that breaks the lock: changing a base rule instead of adding a desktop override. If a value is edited outside the media query, mobile changes too. Everything desktop-specific must sit inside @media (min-width: 750px).

Two more that leak across both: changing the HTML structure, and changing a shared design token. Flag either if your design needs it.

Fixed behaviour — please design around these

  • Sticky bar already has a desktop variant: 1240px wide, Playfair title, no thumbnail, larger button. It reveals only once the buy box has scrolled past.
  • Add to Cart goes straight to checkout.
  • No price is shown anywhere on the page by choice.
  • Product has no images. The gallery runs on two fallback blocks; step photos and expert clips are placeholders.

What to hand back

  1. Design at 1440px, and 1024px if the layout differs there.
  2. One artboard per section is easiest to translate — the hero especially.
  3. Export the .dc.html file and send it here. Not a PDF or screenshot: the HTML carries real hex values, sizes and spacing, so nothing gets eyeballed.
  4. Say which sections are final and which are exploratory.

I will translate each artboard into @media (min-width: 750px) blocks, then verify mobile is byte-identical at 320/360/390/430 before and after. If anything in the design can't be done without touching mobile, I'll flag it rather than quietly change it.
